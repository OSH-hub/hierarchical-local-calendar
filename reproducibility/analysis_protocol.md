# Analysis protocol (extract)

Frozen parent-protocol SHA-256: 12f97c7e0b82a4bb30cc50a54182a57094b483e8f669d33a516bc41a4bd5e268



1. Rebuild from the same four frozen daily/surveillance inputs through 2025. Outcomes are recorded county survey values, not laboratory-confirmed biological onset. Retain all-zero archive years in primary analyses. Original issue timestamps/model versions remain unverified.
2. Fixed risk thresholds: AMB/ABR 1, 2, 3; rice 2, 4. W = 45 days, merge gap = 7. Retain W = 30/60 and gaps = 3/14 as sensitivity. Event is first recorded positive county-year survey; POD is any warning in [event−W,event]. Episode FAR uses the previously corrected observation-window rule: positive within window gives hit; false requires an actual survey within the window and final same-year survey>=start+W; otherwise censor/unverifiable categories remain separate.
3. Preserve all-season episode analysis. Separately remove episodes starting strictly after the first positive survey. Same-day starts remain. No-positive county-years remain only when originally verifiable. This is a redefined pre-onset/no-onset sensitivity, not a replacement biological-onset FAR. Apply identical eligibility to risk and calendar episodes.
4. For direct risk/calendar comparisons and alarm burden use identical support: [first valid survey−45 days,last valid survey] within each calendar year, intersected with retained daily observations. Reconstruct episodes on this support; do not compare detection on extended support to cost on a shorter support. Calendars are 1 July–31 August and 15 June–15 September, fixed before the computations. Report paired event ΔPOD with county/year cluster percentile intervals, 5,000 each, as separate sensitivity intervals rather than a guaranteed joint 95% interval. Episode FAR comparisons remain descriptive because fragmentation differs.
5. Matched-budget diagnostic: circularly shift each county-year binary warning series on its exact common-support grid, 100 draws, seed 20261026. Preserve the number of warning days; circular shifts preserve runs apart from the circular boundary. Report the distribution of event POD, not an operational forecast or a causal/randomized experiment. Seasonal exchangeability is not assumed proven.
6. Optional trained seasonal control is specified now: for AMB/rice, use years <= 2019 only. Set calendar window length to rounded mean warning-day count per eligible county-year for each threshold. Choose the start day among valid 1..365 contiguous windows to maximize training event POD, choosing the earliest start on ties; then evaluate unchanged on 2020–2025. No ABR fitted control if earlier years contain no positive event. This historical split remains post hoc, not a blind trial.
7. Report fixed-protocol early/late, individual-year and province-omission sensitivity. No threshold selected using later outcomes. Report prior-negative status and last-negative gap <= 15/30 days; missing or first-observation-positive events must not be relabeled as confirmed incident cases. Include clustered uncertainty where denominators support it and leave unestimable quantities missing.
8. Present event detection together with warning-day burden, verifiable episode outcomes and observation availability. Do not infer fungicide cost, crop benefit, operational superiority or archived model failures without evidence. All comparisons with wide intervals or adverse results remain in the package.
